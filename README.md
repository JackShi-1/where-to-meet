# where-to-meet

一款用于寻找多人聚会折中点的轻量网页工具，当前实现为「聚中点」v1.5 React + Ant Design 前端原型。

## 本地运行

```bash
npm install
npm run dev
```

打开：

```text
http://localhost:5173
```

## v1.5 已实现

- 地图工作台式布局：左侧决策控制台，右侧固定地图区域，占屏幕不到一半。
- React + Ant Design 组件化实现：表单、列表、指标卡、筛选、投票、结果卡片均使用 AntD。
- 无注册房间演示：房间号、复制分享链接、本地成员状态。
- 多人位置采集：支持地址输入、经纬度输入、模糊位置标记、高德定位按钮。
- 折中点计算：基于成员经纬度计算几何中心点。
- 需求标签：必选需求、可选偏好、共同必选交集和偏好统计。
- 候选地点：未配置高德时使用示例 POI；配置 Key 后调用高德 PlaceSearch 周边搜索。
- 交通方式：成员自定义或全局统一驾车、公交/地铁、地铁优先、步行。
- 路线对比：展示每个成员到选中地点的预计耗时和距离，地图上同步显示多人路线。
- 目的地拖动：加载高德地图后可拖动目的地，实时重算路线和排序。
- 投票与结果卡片：候选地点投票，生成可复制的最终结果摘要。

## 构建

```bash
npm run build
```

## 高德地图配置

页面右侧「配置高德 Web Key」里粘贴 Web 端 Key 和安全密钥。它们只保存在当前浏览器的 `localStorage`，没有写入仓库。

生产版本建议增加后端代理、Redis 房间 TTL、Socket.IO 实时同步，并把服务端 API Key 放在后端。
